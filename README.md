Port Meridian — an original open-world crime game in the browser. Explore a sun-soaked coastal city on foot and by car, steal cars, outrun the Meridian police, climb the wanted ladder, and play through six story missions as wheelman Rex Calloway takes on the Meridian Job. Traffic, pedestrians, combat, a minimap HUD, a save system, and synthesized sound — all from static files, no network, built on three.js.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. Click to start, WASD to move/drive, E to steal a car, mouse to look around.
